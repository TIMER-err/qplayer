# QPlayer 界面

共享界面采用“内容优先”的沉浸式设计：详情页以大封面头图和强调色渐变开场，根页面使用大标题，播放条悬浮在内容上方。控件仍使用 `miuix.Core`。组件库来自 `TIMER-err/miuix-qml` 的 `ad7dc8c`，源码、版本信息和本地补丁记录在 `shared-qml/miuix/`。应用布局与数据适配放在该目录之外，便于后续同步组件库。

## 设计令牌

- `shared-qml/design/Ui.qml` 是应用级单例（`import design`）。间距、页面边距、圆角、字号、字重、组件尺寸、动效时长和语义颜色都从这里读取。页面不再使用散落的颜色字面值。
- 页面水平边距由 `Ui.gutter(width)` 决定：紧凑布局 16，中等布局 24，宽屏 32。根页面标题、路由页返回按钮图标、头图封面和列表内容都对齐这条边距。
- 断点：宽度小于 600 为紧凑布局，600–839 为中等布局，840 及以上为宽屏。宽度以界面缩放后的逻辑像素计算。
- 语义颜色由 Miuix 主题派生，深浅主题和莫奈取色继续生效。`Theme.dynamicColors` 由 `settings.monet` 控制，深浅主题绑定 `StyleManager.isDarkTheme`；封面种子色仍由 `PlayerController` 写入 `StyleManager`。
- qml4j 只把 `DemiBold` 及以上的字重渲染为粗体，因此界面只使用常规与粗体两种字重。渐变色标必须使用 `#AARRGGBB` 字符串，由 `Ui.hexAlpha` 生成。

## 外壳与导航

- 宽屏侧栏宽 232，中等布局收为 80 的图标栏，紧凑布局改用底部导航。侧栏分为根页面（推荐、搜索、本地、我的）、“更多”（最近播放、已下载、插件播放器操作、睡眠定时）和固定在底部的桌面歌词、账号与设置。中间部分可滚动，窗口较矮或界面放大时不会裁掉入口。
- 侧栏和紧凑布局的溢出菜单共用 `components/AppActions.qml`。入口顺序、图标、文字和行为只定义一次。打开的路由页会高亮对应入口。
- 根页面顶部是 `RootHeader`：左侧大标题，右侧凝彩、移动端音量、播放队列，紧凑布局另有溢出菜单。
- 路由页使用 `RouteHeader`：只有一个返回按钮，不再提供“主页”按钮；根页面从侧栏或底部导航返回。标题在页面头图滚出后淡入，内容滚到页头下方时页头显示背景和细分隔线。最多显示约三个操作，其余操作进入溢出菜单。
- 从歌单页打开播放队列时压入路由栈，返回后回到原歌单。
- 宿主下发的返回键和桌面 Esc 先关闭打开的对话框、下拉框和菜单，再处理页面导航。
- 播放条悬浮在内容上方，圆角 20，带细描边。宽度不小于 720 时，左侧为封面和歌名，中间为播放模式、上一首、播放/暂停、下一首、收藏和可拖动进度条，右侧为桌面音量。较窄时显示封面、歌名、收藏、播放/暂停、下一首，并在底边显示细进度条。进度条在按下时预览位置，松开后才跳转。
- 应用更新下载时，播放条上方显示带进度的浮动胶囊。调试日志使用与路由页一致的页头。

## 界面缩放

- “设置 → 外观 → 界面缩放”可在 80%–150% 之间按 5% 调整，默认 100%，存储键为 `uiScale`。该值与系统显示缩放相乘，放大或缩小所有页面、控件、宿主绘制的歌词页和凝彩。
- 滑块在松开时写入设置，避免拖动过程中重新布局打断手势。桌面宿主立即更新窗口最小尺寸、指针与输入法坐标及封面解码分辨率；Android 宿主在下一帧调整根尺寸、触摸坐标和封面解码分辨率。
- 断点按缩放后的逻辑宽度计算：同一窗口放大后可能从宽屏切换为中等或紧凑布局。

## 页面

- 推荐页：问候语以小字显示，不再与大标题重复。有每日推荐时显示带日期、数量、播放按钮和叠放封面的头图卡片。各分区使用统一的 `SectionHeader`，卡片列数随宽度变化。首次加载显示网格轮廓，失败时显示带重试按钮的空状态。首页使用 Miuix 下拉刷新；只有从列表顶部开始的连续拖动能进入刷新区，滚轮到顶不显示回弹。默认先显示推荐歌单、再显示每日推荐，可在设置中开启“每日推荐置顶”。
- 搜索页：顶部固定圆角搜索框和“歌曲 / 专辑 / 歌手 / 歌单”胶囊分类。空闲时显示可单独删除的历史记录和排行热搜，前三名使用强调色。结果为统一歌曲列表或窗口化的卡片网格，并提供加载中和无结果状态。
- 歌单、专辑、歌手卡片使用同一外观：铺满的封面（圆角 14）、最多两行标题和说明文字，悬停时显示整卡背景。歌手卡片使用圆形头像。
- 本地页：列表头部显示筛选后的歌曲数量和总时长、“播放全部”与“随机播放”，以及排序和分组胶囊。再次点击当前排序胶囊会切换升降序。
- “我的”页：歌单类型使用胶囊标签，工具栏提供导入、网格/列表切换和排序。新建歌单使用单个悬浮按钮。
- 播放队列、最近播放和已下载：路由页头下方是标题、数量和主要操作；标题滚出后进入页头。
- 歌单、本地歌单、专辑和歌手详情页共用同一结构：悬浮的 `RouteHeader` 覆盖在一个滚动列表上，列表头部为 `HeroHeader`（封面、类型、标题、可点击的副标题、元信息和操作行）。本地歌单的收录来源在头图下方展开。歌手页包含简介、热门歌曲和窗口化的专辑网格。
- 歌曲行保持 64 行高和 48 封面。正在播放的歌曲使用强调色、粗体和均衡器标记；宽行显示时长；桌面行在悬停时显示更多按钮。
- 歌单多选栏只在所选歌曲全部已喜欢时显示“取消喜欢”；选中未喜欢的歌曲时不提供该操作。
- 音源歌单和本地歌单在滚动超过半屏（最少 128dp、最多 240dp）后显示返回顶部按钮。
- 最近播放由宿主统一记录本地歌曲和插件歌曲，无需登录。记录在实际开始播放后加入，按完整歌曲身份去重并置顶，最多保留 200 首；只恢复队列、播放失败及暂停恢复不新增记录。最近播放独立保留本地封面、缩略图和内嵌歌词的派生文件，曲库重新扫描或更换目录不会删除这些历史资源。外置歌词仍引用原文件。资源写入在 IO 线程完成，历史淘汰后清理不再引用的副本；不复制音频，也不保存临时播放地址或请求头。

## 设置、账号与弹窗

- 设置页在宽屏使用左侧分类列表和右侧内容；中等和紧凑布局使用横向分类标签。设置行仍完全由 `SettingsCatalog` 生成，对象名为 `setting_<key>`。每组设置为一张卡片，行间使用细分隔线，最小行高 56。
- 设置开关和滑块在适配层接收后续宿主值更新，防止控件交互写入自身属性后失去与外部设置的同步。
- 插件详情页和账号页使用带强调色渐变的头图。账号页按音源列出账号，未登录时可直接登录。插件详情页的“主音源”是普通操作行：点击整行设为主音源，右侧显示强调色文字和箭头；已是主音源时显示对勾。
- 登录、睡眠定时、音量、下载音质、字体、音源配置等弹窗使用 Miuix `Dialog`。弹窗打开后，内容引起的高度变化使用 240ms 缓出动画。
- 下载音质弹窗的选项、按钮尺寸和选择函数由 `Dialog` 自身持有。根层重挂后，`Repeater` 委托不引用弹窗外层的 id；标准、较高、极高、无损与 Hi-Res 五个选项均保留。
- 应用音量不占用设置页条目：桌面播放条显示音量按钮，点击后在播放条上方弹出 0–100% 滑块和静音按钮；移动端从页面顶部按钮打开音量弹窗。值跨启动持久化，并直接控制 QPlayer 音频后端。
- Button 和 IconButton 的鼠标点击不强制获取焦点；Tab 导航的焦点提示保持可见。桌面空格键先交给当前可见的键盘焦点控件，未被处理时才切换播放状态。
- 应用内临时通知（`components/NoticeStack.qml`）是底部居中的反色胶囊，宽度随文字变化，最多换行三行、堆叠三条；位于浮动播放条和底部导航上方，点击即可关闭，约 3 秒后自动淡出。歌词独立合成时复用同一组件。
- 弹出菜单（Miuix `Menu` 本地补丁）使用 44dp 行高、内缩圆角的悬停与按压高亮、20dp 次要色图标、15dp 文字和子菜单箭头，外层 18dp 圆角加细描边，入场从 0.92 倍缩放展开。

## 歌词页与凝彩

- 歌词页布局几何与宿主合成器保持同步，未作改动。控件改为白色系：播放/暂停为白色圆形按钮，比两侧按钮大；播放模式在默认状态下降低亮度；收藏使用 `Ui.like`。歌词进度条使用白色与半透明白色，避免浅色主题强调色在深色背景上不可见。
- 歌词偏移面板拆分为 `components/LyricOffsetPanel.qml`，尺寸和位置不变。
- 凝彩控制条、全屏退出提示、桌面音量弹层、桌面歌词控制按钮和 Windows 标题栏统一使用设计令牌。

## 动效

- 动效只在状态切换时运行，静止画面不保留循环动画；骨架屏和加载指示器只在可见时运行。
- 侧栏根页面共用一块选中背景，切换时以 260ms 缓出滑到新入口；打开路由页时淡出。侧栏项按下时图标轻微缩小，选中颜色渐变过渡。
- 歌单、专辑、歌手卡片按下时缩到 0.97，松开后恢复；每日推荐卡片悬停时叠放封面向左展开。
- 播放条和歌词页的播放/暂停、收藏按钮点击后有短促的缩放反馈（`components/Pop.qml`）。`Pop` 放在文件根级，不作为 Miuix `IconButton` 实例的子对象声明。
- 进度条悬停或拖动时轨道加粗，圆点从播放位置放大出现，拖动时再略微放大。
- 歌单、专辑、歌手详情页和推荐页在数据到达后淡入；歌单原地刷新且已有歌曲时不重新淡入。搜索结果到达时淡入，新查询清空结果时淡出。搜索历史展开箭头旋转过渡。
- 歌曲行的占位音符只在没有封面路径时绘制；歌手名的测宽文本只在桌面歌手链接可用时排版，减少滚动时每行的绘制和排版。

## 文本排版

界面与歌词共用 qml4j 的 `UnicodeBreaks`，基于 ICU 的 [Unicode 断行](https://www.unicode.org/reports/tr14/)和[扩展字素边界](https://www.unicode.org/reports/tr29/)，不再各自维护中日韩标点或组合字符表。

- 正常换行遵守标点禁则；超长词按安全字素边界拆分，不拆开组合附加符、旗帜、ZWJ emoji 或正字法连写，不跨越不换行空格与 word joiner。
- 主歌词、翻译、罗马音和凝彩保留显式换行。主歌词需要拆分显示片段时，时间范围连续覆盖原片段，原始文本与时间轴不变。
- 断行分析随布局缓存生成，复用已有 HarfBuzz 测量结果，不在播放帧内重复分段。

## 液体玻璃特效

“设置 → 外观 → 液体玻璃特效”是所有液体玻璃组件的统一开关，默认关闭。存储键沿用 `liquidGlassNavigation`，保留已有开关状态。当前接入紧凑布局（窗口宽度小于 600dp）的底栏和 MiniPlayer；设置项直接说明此范围。关闭后两个背景、封面形状和进度样式一起恢复普通模式。宽屏继续使用导航侧栏和普通 MiniPlayer。

- 参考 [Miuix `IosLiquidGlassNavigationBar`](https://github.com/compose-miuix-ui/miuix/blob/b587aaf2c907c77a8c3c02d8df0aede2937ef8f0/example/shared/src/commonMain/kotlin/component/liquid/LiquidGlassNavigationBar.kt)，固定版本 `b587aaf2`。底座高 64dp、水平边距 24dp、内边距 4dp，选中镜片高 56dp；底部有系统 inset 时留 `inset + 8dp`，否则留 36dp。
- MiniPlayer 高 80dp、圆角为 `height / 2`（40dp），与底栏共用 24dp 水平边距。封面为直径 60dp 的圆形，外侧是直径 68dp、线宽 3dp 的环形进度，替代顶部直线。点封面中心打开歌词，点外圈按十二点起顺时针定位进度；加载期间旋转进度弧，完成当前一圈后平滑衔接实际进度。背景单独采样，文字和播放控件正常绘制，不添加选中镜片或拖动形变。
- 加载环只更新固定画布内的圆弧角度，不旋转栅格图像；按每秒 360° 匀速运动。`MiniPlayerLoadingAnimation` 接入现有帧循环，以单调时间计算一秒周期的相位，避开 qml4j 0.2.33 循环重启多等一帧的问题，不增加定时器。普通模式仍按 `InOutSine` 计算扫条位移；完成加载后以 450ms `OutCubic` 衔接实际进度，停止或隐藏时不保持活动动画时钟。
- 页面视口延伸至窗口底部，内容可从两个浮动胶囊及其间隙下方经过。各页仅在滚动内容末尾增加底部留白，保证最后一项能滚到 MiniPlayer 上方；页面 FAB、多选操作栏同步避让。关闭开关时留白为零，恢复原视口边界。
- 使用当前页面的局部 GPU 背板，移植上游增艳、模糊、圆角折射、色散、双峰高光、按压光斑和内阴影。导航栏的普通图标与强调色图标分别合成；两个胶囊各自只采样附近背景，不对整页应用滤镜。
- 点击或横向拖动均可切换标签；拖动期间镜片连续跟随，松手后提交目标页，取消手势则返回当前页。位置、按压、缩放及速度形变沿用上游弹簧参数，速度由同样的多帧二次拟合计算。
- Android 仅在前台、开关开启且手机底栏可见时监听旋转向量传感器；重力高光按 3° 量化，退出前台即注销。关闭功能时不创建玻璃 GPU 资源。
- `LiquidGlassNode` 在底栏和 MiniPlayer 各自原有的 QML 层级绘制；仅这两个顶层缓存边界走 qml4j 0.2.33 的实时绘制路径，其余页面保留图片缓存。隐藏导航图标源在尺寸或模型变化时单独布局，使矢量图标的 Loader 也能初始化；不逐帧重新布局图标。
- 只缓存与背景无关的外阴影掩膜及其最终模糊结果，背板仍逐帧实时采样。最终阴影按设备像素栅格复用；位置、尺寸、密度或深浅主题变化时失效。持续移动、旋转或非均匀缩放时保留原滤镜路径。缓存以固定 GPU 显存换取减少重复模糊，尺寸变化、关闭特效或销毁图形上下文时释放。
- 折射中间层只绘制胶囊覆盖区及两纹理像素的采样保护带，输入背板的 40dp 边界保持不变。模糊核、折射、色散、高光、阴影强度、分辨率和动画帧率均不降低。

## 虚拟列表约束

歌曲列表和网格保留 qml4j 的窗口化 `Repeater.windowStart/windowCount`，模型仍是完整列表，delegate 的 `index` 始终是全局索引。不把整个模型切片后交给普通 Repeater，也不为整份列表创建 Card 效果层。

- 歌曲固定行高，窗口为可见行加上下缓冲；640dp 高度、64dp 行高时最多 17 个歌曲 delegate。
- 下拉刷新容器接管滚动时，VirtualSongList 按外部视口高度与滚动位置计算窗口，内部不再处理滚动，避免嵌套滚动冲突或按完整列表高度实例化所有歌曲。
- 歌单网格的坐标与窗口计算共用同一个浮点步长，避免长距离滚动的取整累积误差。
- 首页音源分区歌单、搜索专辑/歌手、歌手页专辑/歌曲及字体/本地分组选择器也采用窗口化。
- 首页分区歌单按纵坐标做二分查找，滚动不遍历整份卡片模型。
- 首页分区歌单、推荐歌单和每日推荐歌曲的窗口数量都不随滚动位置变化，保留仍在窗口内的卡片和已解码封面，避免整批重建造成闪烁。窗口从 0 增长会在同一帧创建整批行和封面；点击每日推荐卡片的滚动动画曾因此在中途停顿约 150ms。
- 列表缩短时校正滚动位置；歌曲复用时直接更新封面路径并关闭旧歌曲菜单。封面加载范围由列表窗口及其缓冲控制，不再给每一行绑定滚动位置、维护第二套视口门控。
- 首页与“我的”根标签切换时保留已加载的窗口和滚动状态；隐藏或视口外的歌单卡片暂停标题跑马灯。详情页等页面仍按各自可见性管理数据窗口。
- “我的”网格和列表模式首次使用时才加载对应模型；服务端返回内容、顺序均相同的歌单数据时，不替换现有模型。
- 歌单网格复用时立即更新基础坐标，只对拖动排序产生的偏移做动画。取消手势、开始滚动、切换页面或更换模型时取消拖动，不提交排序；长按开始前重新核对按压状态和歌单身份。
- 歌曲来源标签与标题使用响应式位置和宽度，避免缓存布局下复用后锚点滞后；来源标签最多 112dp，窄屏时缩短并省略文字，空间不足时隐藏，保证歌曲标题和标签不重叠。
- 不给歌曲行增加每帧计时器或逐行 GPU 离屏效果。保留固定坐标、`cachedLayout` 和封面按显示分辨率解码。
- 歌曲上下文菜单由列表持有一份（`VirtualSongList`、推荐页每日推荐、歌手页热门歌曲），行通过 `sharedMenu` 使用，打开前写入当前歌曲。每行一个菜单约占行内节点的三成，且打开歌单时会随整批行一起重建。菜单不能在行创建后再延迟加载：qml4j 中行创建后才加入的 Loader 子项会使该行的悬停和右键失效。
