# QPlayer 的 Miuix 界面

共享界面使用 `miuix.Core`。组件库来自 `TIMER-err/miuix-qml` 的 `ad7dc8c`，源码、版本信息和许可保存在 `shared-qml/miuix/`。应用布局与数据适配放在该目录之外，便于后续同步组件库。本次迁移不修改 qml4j 引擎。

## 页面与主题

- 设置始终采用单列布局，最大内容宽度 880dp。`SettingsCatalog` 按主题分组，`SettingGroup` 为同组设置提供一个容器。开关、下拉选择、路径和动作使用 Miuix 设置行；文字较长时换行。
- 设置分组会随依赖项动态计算可见行；组内所有设置项都被隐藏时，标题和卡片一起退出布局，不保留空白容器。
- 页面标签栏、设置分类与主题、字重等设置项统一使用 `TabRowWithContour`，内容过多时仍可横向滚动。本地页排序和分组筛选恢复原版小胶囊控件，保留虚拟化的筛选值选择器。窄屏顶部保留常用操作，其余操作进入菜单。
- 桌面窗口最小为 360×480 逻辑像素，防止缩窗后页面和播放控件被裁切。尺寸下限随显示器 DPI 更新，并在窗口重建时重新设置；全屏不受此限制。
- 歌单、专辑、歌手卡片突出封面；歌单详情增加封面、歌曲数量和播放入口。播放器、空状态、账号与插件页面共用 Miuix 的颜色与交互反馈。
- 登录、字体、本地分组、插件及确认弹窗使用 Miuix `Dialog`。歌词时间偏移面板保留在歌词子树内，采用 Miuix 表面与控件，因为歌词由宿主独立合成。偏移面板保持原有尺寸、排版和位置，仅将展开、收起的动效参数与音量弹窗对齐，缩放原点为弹窗中心。
- `Theme.dynamicColors` 由 `settings.monet` 控制，深浅主题继续绑定 `StyleManager.isDarkTheme`。封面种子色仍由 `PlayerController` 写入内置 `StyleManager`，没有第二条 QML 种子色绑定。关闭莫奈后恢复 Miuix 默认配色。
- 设置开关和滑块在适配层接收后续宿主值更新，防止控件交互写入自身属性后失去与外部设置的同步。
- 应用音量不占用设置页条目：桌面 MiniPlayer 仅显示音量按钮，点击后在播放器上方弹出 0–100% 滑块和静音按钮。展开使用 200ms 缩放与 150ms 渐显，收起使用 150ms 缩放与渐隐。点击外部、按 Esc 或缩放窗口会关闭弹层。移动端仍从页面顶部按钮打开音量对话框。值跨启动持久化，并直接控制 QPlayer 音频后端，不改变系统媒体音量。
- Button 和 IconButton 的鼠标点击不再强制获取焦点，鼠标按下时清除旧键盘焦点，避免鼠标离开或关闭弹窗后残留焦点高亮；Tab 导航的焦点提示保持可见。
- 空状态的图标背景使用明确的 64dp 正方形尺寸；图标、文字和按钮共享同一份受限内容宽度，完整占位内容在可用区域内水平、竖直居中，窗口由宽屏收窄后也不会沿用旧的子项宽度。标签栏内容放得下时整体居中，溢出时继续横向滚动；普通标签栏背景透明，带轮廓的背景只包住标签内容。
- 宽屏导航展开时，在线音源未配置占位层由主内容容器统一承载；音源选择、本地页、首页、搜索和“我的”的占位内容始终相对当前右侧面板居中，不以包含导航栏的整个窗口为参照。
- 弹窗打开后，内容引起的高度变化使用 240ms 缓出动画，宽度变化立即生效；开关弹窗仍使用原来的进入和退出动画。组件修复已同步至上游，版本记录在 `shared-qml/miuix/UPSTREAM.md`。
- 应用内临时通知使用底部居中的浮动卡片，最多堆叠三条；卡片带状态图标、关闭按钮、剩余时间进度、描边和阴影，并以淡入上浮/淡出下沉动画替代原来的 MD3 Snackbar 外观。歌词独立合成时复用同一组件。
- 歌词页的横竖屏播放进度使用保留的 `components/LyricProgress.qml`，沿用迁移前的波浪、双段加载动画、加载完成衔接、进度同步和隐藏时停动逻辑，仅接入 Miuix 主题颜色。歌词偏移调节仍使用 Miuix Slider。
- 歌词页控制栏保留播放模式、上一首、播放/暂停、下一首和收藏，播放/暂停保持居中，不显示队列按钮。全宽歌词模式的控制条两侧均留 28dp，按整页中心定位，不再为已移除的右侧操作保留非对称空位。播放队列入口保留在主界面顶部。
- 歌单、专辑和歌手详情页的加载指示器采用 Gallery 默认的 20dp 尺寸与透明背景。
- 关于页检查更新使用 24dp 前置图标，QPlayer 版本条目不显示链接图标。字体设置与已安装字体列表分为两个弹窗；已安装字体弹窗的外层内容固定在可用高度内，仅内部虚拟列表负责滚动并显示滚动条，字体项保持左对齐、垂直居中。MiniPlayer 封面为 60dp，圆角 10dp。
- 导航栏标签使用完整可用宽度，并随展开/折叠调整文本对齐方式，避免预估文字宽度导致有空间时仍显示省略号。
- 首页使用 Miuix 下拉刷新；只有从列表顶部开始的连续拖动能进入刷新区，从列表中段拖回顶部会直接停在顶部，滚轮到顶不显示回弹，触摸从顶部下拉仍可刷新。默认先显示推荐歌单、再显示每日推荐，可在设置中开启“每日推荐置顶”。歌单页使用直接滚动的虚拟歌曲列表，不提供下拉刷新。队列删除按钮使用 40dp IconButton，右侧留 16dp 内边距。
- 音源歌单和本地歌单在滚动超过半屏（最少 128dp、最多 240dp）后显示组件库的标准 60dp FAB；按钮以 160ms 淡入并从 0.82 倍缩放到原尺寸，回到阈值以内时反向隐藏，点击后以 220ms 缓出动画滚动返回列表顶部。
- 长歌曲列表、歌单网格、详情页、设置页、账户页、搜索结果、导航容器及有高度上限的弹窗、菜单、选择器均使用按需显示的 Miuix 滚动条；滚动、悬停或拖动时淡入，内容未溢出时不占视觉空间。横向标签栏保留滑动和选中指示器，不叠加会与指示器冲突的滚动条。

## 液体玻璃特效

“设置 → 外观 → 液体玻璃特效”是所有液体玻璃组件的统一开关，默认关闭。存储键沿用 `liquidGlassNavigation`，保留已有开关状态。当前接入手机布局（宽度小于 600dp）的底栏和 MiniPlayer；关闭后两个背景、封面形状和进度样式一起恢复普通模式。宽屏继续使用导航侧栏和普通 MiniPlayer。

- 参考 [Miuix `IosLiquidGlassNavigationBar`](https://github.com/compose-miuix-ui/miuix/blob/b587aaf2c907c77a8c3c02d8df0aede2937ef8f0/example/shared/src/commonMain/kotlin/component/liquid/LiquidGlassNavigationBar.kt)，固定版本 `b587aaf2`。底座高 64dp、水平边距 24dp、内边距 4dp，选中镜片高 56dp；底部有系统 inset 时留 `inset + 8dp`，否则留 36dp。
- MiniPlayer 高 80dp、圆角为 `height / 2`（40dp），与底栏共用 24dp 水平边距。封面为直径 60dp 的圆形，外侧是直径 68dp、线宽 3dp 的环形进度，替代顶部直线。点封面中心打开歌词，点外圈按十二点起顺时针定位进度；加载期间旋转进度弧，完成当前一圈后平滑衔接实际进度。背景单独采样，文字和播放控件正常绘制，不添加选中镜片或拖动形变。
- 加载环只更新固定画布内的圆弧角度，不旋转栅格图像；按每秒 360° 匀速运动。`MiniPlayerLoadingAnimation` 接入现有帧循环，以单调时间计算一秒周期的相位，避开 qml4j 0.2.33 循环重启多等一帧的问题，不增加定时器。普通模式仍按 `InOutSine` 计算扫条位移；完成加载后以 450ms `OutCubic` 衔接实际进度，停止或隐藏时不保持活动动画时钟。
- 页面视口延伸至窗口底部，内容可从两个浮动胶囊及其间隙下方经过。各页仅在滚动内容末尾增加底部留白，保证最后一项能滚到 MiniPlayer 上方；页面 FAB、多选操作栏同步避让。关闭开关时留白为零，恢复原视口边界。
- 使用当前页面的局部 GPU 背板，移植上游增艳、模糊、圆角折射、色散、双峰高光、按压光斑和内阴影。导航栏的普通图标与强调色图标分别合成；两个胶囊各自只采样附近背景，不对整页应用滤镜。
- 点击或横向拖动均可切换标签；拖动期间镜片连续跟随，松手后提交目标页，取消手势则返回当前页。位置、按压、缩放及速度形变沿用上游弹簧参数，速度由同样的多帧二次拟合计算。
- Android 仅在前台、开关开启且手机底栏可见时监听旋转向量传感器；重力高光按 3° 量化，退出前台即注销。关闭功能时不创建玻璃 GPU 资源。
- `LiquidGlassNode` 在底栏和 MiniPlayer 各自原有的 QML 层级绘制；仅这两个顶层缓存边界走 qml4j 0.2.33 的实时绘制路径，其余页面保留图片缓存。隐藏导航图标源在尺寸或模型变化时单独布局，使矢量图标的 Loader 也能初始化；不逐帧重新布局图标。

## 虚拟列表约束

歌曲列表和网格保留 qml4j 的窗口化 `Repeater.windowStart/windowCount`，模型仍是完整列表，delegate 的 `index` 始终是全局索引。不把整个模型切片后交给普通 Repeater，也不为整份列表创建 Card 效果层。

- 歌曲固定行高，窗口为可见行加上下缓冲；640dp 高度、64dp 行高时最多 17 个歌曲 delegate。
- 下拉刷新容器接管滚动时，VirtualSongList 按外部视口高度与滚动位置计算窗口，内部不再处理滚动，避免嵌套滚动冲突或按完整列表高度实例化所有歌曲。
- 歌单网格的坐标与窗口计算共用同一个浮点步长，避免长距离滚动的取整累积误差。
- 首页音源分区歌单、搜索专辑/歌手、歌手页专辑/歌曲及字体/本地分组选择器也采用窗口化。
- 首页分区歌单按纵坐标做二分查找，滚动不遍历整份卡片模型。
- 首页分区歌单的预加载窗口数量在滚动中保持稳定，保留仍在窗口内的卡片和已解码封面，避免整批重建造成闪烁。
- 列表缩短时校正滚动位置；歌曲复用时直接更新封面路径并关闭旧歌曲菜单。封面加载范围由列表窗口及其缓冲控制，不再给每一行绑定滚动位置、维护第二套视口门控。
- 首页与“我的”根标签切换时保留已加载的窗口和滚动状态；隐藏或视口外的歌单卡片暂停标题跑马灯。详情页等页面仍按各自可见性管理数据窗口。
- “我的”网格和列表模式首次使用时才加载对应模型；服务端返回内容、顺序均相同的歌单数据时，不替换现有模型。
- 歌单网格复用时立即更新基础坐标，只对拖动排序产生的偏移做动画。取消手势、开始滚动、切换页面或更换模型时取消拖动，不提交排序；长按开始前重新核对按压状态和歌单身份。
- 歌曲来源标签与标题使用响应式位置和宽度，避免缓存布局下复用后锚点滞后；来源标签最多 112dp，窄屏时缩短并省略文字，空间不足时隐藏，保证歌曲标题和标签不重叠。
- 不给歌曲行增加每帧计时器或逐行 GPU 离屏效果。保留固定坐标、`cachedLayout` 和封面按显示分辨率解码。
