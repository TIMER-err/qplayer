# QPlayer 的 Miuix 界面

共享界面使用 `miuix.Core`。组件库来自 `TIMER-err/miuix-qml` 的 `ad7dc8c`，源码、版本信息和许可保存在 `shared-qml/miuix/`。应用布局与数据适配放在该目录之外，便于后续同步组件库。本次迁移不修改 qml4j 引擎。

## 页面与主题

- 设置始终采用单列布局，最大内容宽度 880dp。`SettingsCatalog` 按主题分组，`SettingGroup` 为同组设置提供一个容器。开关、下拉选择、路径和动作使用 Miuix 设置行；文字较长时换行。
- 页面标签栏、设置分类与主题、字重等设置项统一使用 `TabRowWithContour`，内容过多时仍可横向滚动。本地页排序和分组筛选恢复原版小胶囊控件，保留虚拟化的筛选值选择器。窄屏顶部保留常用操作，其余操作进入菜单。
- 歌单、专辑、歌手卡片突出封面；歌单详情增加封面、歌曲数量和播放入口。播放器、空状态、账号与插件页面共用 Miuix 的颜色与交互反馈。
- 登录、字体、本地分组、插件及确认弹窗使用 Miuix `Dialog`。歌词时间偏移面板保留在歌词子树内，采用 Miuix 表面与控件，因为歌词由宿主独立合成。
- `Theme.dynamicColors` 由 `settings.monet` 控制，深浅主题继续绑定 `StyleManager.isDarkTheme`。封面种子色仍由 `PlayerController` 写入内置 `StyleManager`，没有第二条 QML 种子色绑定。关闭莫奈后恢复 Miuix 默认配色。
- 设置开关和滑块在适配层接收后续宿主值更新，防止控件交互写入自身属性后失去与外部设置的同步。
- Button 和 IconButton 的鼠标点击不再强制获取焦点，鼠标按下时清除旧键盘焦点，避免鼠标离开或关闭弹窗后残留焦点高亮；Tab 导航的焦点提示保持可见。
- 空状态的图标背景使用明确的 64dp 正方形尺寸，与文字和按钮共享水平中心。标签栏内容放得下时整体居中，溢出时继续横向滚动；普通标签栏背景透明，带轮廓的背景只包住标签内容。
- 弹窗打开后，内容引起的高度变化使用 240ms 缓出动画，宽度变化立即生效；开关弹窗仍使用原来的进入和退出动画。组件修复已同步至上游，版本记录在 `shared-qml/miuix/UPSTREAM.md`。
- 歌词页的横竖屏播放进度使用保留的 `components/LyricProgress.qml`，沿用迁移前的波浪、双段加载动画、加载完成衔接、进度同步和隐藏时停动逻辑，仅接入 Miuix 主题颜色。歌词偏移调节仍使用 Miuix Slider。
- 歌单、专辑和歌手详情页的加载指示器采用 Gallery 默认的 20dp 尺寸与透明背景。
- 关于页检查更新使用 24dp 前置图标，QPlayer 版本条目不显示链接图标。字体设置与已安装字体列表分为两个弹窗，字体列表固定左对齐、垂直居中并保持虚拟化。MiniPlayer 封面为 60dp，圆角 10dp。
- 导航栏标签使用完整可用宽度，并随展开/折叠调整文本对齐方式，避免预估文字宽度导致有空间时仍显示省略号。
- 首页使用 Miuix 下拉刷新。歌单页使用直接滚动的虚拟歌曲列表，不提供下拉刷新。队列删除按钮使用 40dp IconButton，右侧留 16dp 内边距。

## 虚拟列表约束

歌曲列表和网格保留 qml4j 的窗口化 `Repeater.windowStart/windowCount`，模型仍是完整列表，delegate 的 `index` 始终是全局索引。不把整个模型切片后交给普通 Repeater，也不为整份列表创建 Card 效果层。

- 歌曲固定行高，窗口为可见行加上下缓冲；640dp 高度、64dp 行高时最多 17 个歌曲 delegate。
- 下拉刷新容器接管滚动时，VirtualSongList 按外部视口高度与滚动位置计算窗口，内部不再处理滚动，避免嵌套滚动冲突或按完整列表高度实例化所有歌曲。
- 歌单网格的坐标与窗口计算共用同一个浮点步长，避免长距离滚动的取整累积误差。
- 首页音源分区歌单、搜索专辑/歌手、歌手页专辑/歌曲及字体/本地分组选择器也采用窗口化。
- 首页分区歌单按纵坐标做二分查找，滚动不遍历整份卡片模型。
- 首页分区歌单的预加载窗口数量在滚动中保持稳定，保留仍在窗口内的卡片和已解码封面，避免整批重建造成闪烁。
- 列表缩短时校正滚动位置；歌曲复用时更新封面加载状态并关闭旧歌曲菜单。页面隐藏时释放其数据窗口。
- 歌曲来源标签与标题使用响应式位置和宽度，避免缓存布局下复用后锚点滞后；来源标签最多 112dp，窄屏时缩短并省略文字，空间不足时隐藏，保证歌曲标题和标签不重叠。
- 不给歌曲行增加每帧计时器或逐行 GPU 离屏效果。保留固定坐标、`cachedLayout` 和封面按显示分辨率解码。
